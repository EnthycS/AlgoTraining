## A

### Problem Statement

You are given a string S of length N consisting of lowercase English letters.  
We denote the i-th character of S by Si​.  
Print the string of length 2N obtained by concatenating S1​,S1​,S2​,S2​,…,SN​, and SN​ in this order.  
For example, if S is `beginner`, print `bbeeggiinnnneerr`.

### Constraints

- N is an integer such that 1≤N≤50.
- S is a string of length N consisting of lowercase English letters.

##### 代码：

```cpp
#include <bits/stdc++.h>

using namespace std;

void solve(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    string s;
    string res= "";
    cin>>n;
    cin>>s;
    for(int i = 0 ; i < n ; i++){
        char ch = s[i];
        res += ch;
        res += ch;
    }

    cout<<res;

}

int main(){
    solve();
    return 0;
}
```

## B

### Problem Statement

You are given a sequence A=(A0​,A1​,…,A63​) of length 64 consisting of 0 and 1.

Find A0​2^0+A1​2^1+⋯+A63​2^63.

### Constraints

- Ai​ is 0 or 1.

##### 代码：

```cpp
#include <bits/stdc++.h>

using namespace std;
using ull = unsigned long long;

void solve(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    ull res = 0ULL;
    ull pows = 1ULL;
    int cnt = 0;

    for(int i = 0 ; i < 64 ; i++){
        int t;
        cin>>t;
        if(t == 0){
            pows *= 2;

        }else{
            res += pows;
            pows *= 2;
            cnt++;
        }
    }

    cout<<res;


}

int main(){
    solve();
    return 0;
}
```

## C

### Problem Statement

You are given a sequence A=(A1​,A2​,…,A3N​) of length 3N where each of 1,2,…, and N occurs exactly three times.

For i=1,2,…,N, let f(i) be the index of the middle occurrence of i in A. Sort 1,2,…,N in ascending order of f(i).

Formally, f(i) is defined as follows.

- Suppose that those j such that Aj​=i are j=α,β,γ (α<β<γ). Then, f(i)=β.

### Constraints

- 1≤N≤10^5
- 1≤Aj​≤N
- i occurs in A exactly three times, for each i=1,2,…,N.
- All input values are integers.

##### 思路：

1.记录i三次出现的位置到一个vector之中

2.创建一个pair<int,int>的数组，first位置表示i，second位置表示f(i)，并按照second升序排列

##### 代码：

```cpp
#include <bits/stdc++.h>

using namespace std;

bool cmp(pair<int,int> a , pair<int,int> b){
    return  a.second < b.second;
}
void solve(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin>>n;


    vector<vector<int> > m(n+1);
    int t;

    for(int i = 0 ; i < 3*n ; i++){
        cin>>t;
        m[t].emplace_back(i+1);

    }

    vector<pair<int,int> > f(n+1);//1.数字 2.f(i)

    for(int i = 1 ; i <= n ; i++){
        f[i].first = i;
        f[i].second = m[i][1];
    }

    sort(f.begin(),f.end(),cmp);

    for(int i = 1 ; i <= n ; i++){
        if(i != 1){
            cout<<" ";
        }
        cout<<f[i].first;
    }



}

int main(){
    solve();
    return 0;
}
```

## D

### Problem Statement

Takahashi has decided to enjoy a wired full-course meal consisting of N courses in a restaurant.  
The i-th course is:

- if Xi​=0, an **antidotal** course with a tastiness of Yi​;
- if Xi​=1, a **poisonous** course with a tastiness of Yi​.

When Takahashi eats a course, his state changes as follows:

- Initially, Takahashi has a healthy stomach.
- When he has a **healthy stomach**,
  - if he eats an **antidotal** course, his stomach **remains healthy**;
  - if he eats a **poisonous** course, he **gets an upset stomach**.
- When he has an **upset stomach**,
  - if he eats an **antidotal** course, his stomach **becomes healthy**;
  - if he eats a **poisonous** course, he **dies**.

The meal progresses as follows.

- Repeat the following process for i=1,…,N in this order.
  - First, the i-th course is served to Takahashi.
  - Next, he chooses whether to "eat" or "skip" the course.
    - If he chooses to "eat" it, he eats the i-th course. His state also changes depending on the course he eats.
    - If he chooses to "skip" it, he does not eat the i-th course. This course cannot be served later or kept somehow.
  - Finally, (if his state changes, after the change) if he is not dead,
    - if i=N, he proceeds to the next course.
    - if i=N, he makes it out of the restaurant alive.

An important meeting awaits him, so he must make it out of there alive.  
Find the **maximum possible sum of tastiness of the courses that he eats** (or 0 if he eats nothing) when he decides whether to "eat" or "skip" the courses under that condition.

### Constraints

- All input values are integers.
- 1≤N≤3×10^5
- Xi​∈{0,1}
  - In other words, Xi​ is either 0 or 1.
- −10^9≤Yi​≤10^9

##### 思路：

1.若当前食物为健康食物，则可以有不吃当前食物、上一次吃了健康食物并且吃当前食物、上一次吃了有毒食物并且吃当前食物中选择最大的值

2.若当前食物为有毒食物，则可以不吃当前食物、上一次吃了健康食物并且吃当前食物这两种选择

##### 代码：

```cpp
#include <bits/stdc++.h>

using namespace std;
using ll =  long long;

void solve(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin>>N;
    vector<pair<int, ll> > dishes(N);
    for (int i = 0; i < N; ++i) {
        ll X;
        int Y;
        cin >> Y >> X;
        dishes[i] = make_pair(Y, X); 
    }

    // dp[i][0] = healthy, dp[i][1] = poisoned

    vector<vector<ll>> dp(N + 1, vector<ll>(2));
    dp[0][0] = 0;
    dp[0][1] = LLONG_MIN;

    for(int i = 0 ; i < N ; i++){
        int y = dishes[i].first;
        int x = dishes[i].second;
        dp[i+1][0] = dp[i][0];
        dp[i+1][1] = dp[i][1];
        if(y == 0){
            dp[i+1][0] = max(dp[i+1][0],max(dp[i][0] + x , dp[i][1] + x));

        }else{
            dp[i+1][1] = max(dp[i+1][1],dp[i][0] + x);

        }


    }

    cout<<max(dp[N][1],dp[N][0]);



}

int main(){
    solve();
    return 0;
}
```





## E

### Problem Statement

We have a sequence A=(A1​,A2​,…,AN​) of length N. Initially, all the terms are 0.  
Using an integer K given in the input, we define a function f(A) as follows:

- Let B be the sequence obtained by sorting A in descending order (so that it becomes monotonically non-increasing).
- Then, let f(A)=B1​+B2​+⋯+BK​.

We consider applying Q updates on this sequence.  
Apply the following operation on the sequence A for i=1,2,…,Q in this order, and print the value f(A) at that point after each update.

- Change AXi​​ to Yi​.

### Constraints

- All input values are integers.
- 1≤K≤N≤5×10^5
- 1≤Q≤5×10^5
- 1≤Xi​≤N
- 0≤Yi​≤10^9



##### 思路:

1.使用一个multiset top来存放前K大的数，从小到大排列

2.使用使用一个multiset rest来存放其它的数，从小到大排列

3.首先移除要修改的数，再插入新数，之后要调整top和rest的大小为K和N-K



##### 代码：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int N, K, Q;
    cin >> N >> K >> Q;
    
    vector<int> A(N, 0);
    multiset<int> top, rest;
    
    // 初始时，所有都为0，rest中有N个0，top为空（K可能<N）
    // 我们需要恰好K个元素在top中
    for (int i = 0; i < K; ++i) top.insert(0);
    for (int i = K; i < N; ++i) rest.insert(0);
    
    long long sum = 0; // top中元素的和
    
    auto balance = [&]() {
        while (top.size() < K && !rest.empty()) {
            auto it = prev(rest.end()); // rest的最大元素
            sum += *it;
            top.insert(*it);
            rest.erase(it);
        }
        while (top.size() > K) {
            auto it = top.begin(); // top的最小元素
            sum -= *it;
            rest.insert(*it);
            top.erase(it);
        }
    };
    
    for (int i = 0; i < Q; ++i) {
        int X, Y;
        cin >> X >> Y;
        X--; // 转为0-based
        
        // 移除旧值
        if (top.find(A[X]) != top.end()) {
            sum -= A[X];
            top.erase(top.find(A[X]));
        } else {
            rest.erase(rest.find(A[X]));
        }
        
        // 插入新值
        A[X] = Y;
        if (!top.empty() && Y >= *top.begin()) {
            top.insert(Y);
            sum += Y;
        } else {
            rest.insert(Y);
        }
        
        balance();
        cout << sum << '\n';
    }
    
    return 0;
}

```
